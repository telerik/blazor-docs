# Breaking Changes in 16.0.0

## Icons

Telerik UI for Blazor now uses version 5.0.0 of the Telerik icon packages by default. Some icons previously available as deprecated font icon aliases are removed or renamed. Review the v5.0.0 release notes in the [Icon Packages Changelog](https://www.telerik.com/design-system/docs/foundation/iconography/changelog/).

## Gantt, Grid, TreeList

`Items` replaces the `Item` property in the following argument types:

* `GanttTaskCommandEventArgs`
* `GridCommandEventArgs`
* `TreeListCommandEventArgs`
