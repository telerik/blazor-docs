# Breaking Changes in 16.0.0

## Icons

Telerik UI for Blazor now depends on version 5 of the Telerik icon packages by default. Some icons previously available as deprecated icon aliases are removed or renamed. Review the v5.0.0 release notes in the [Icon Packages Changelog](https://www.telerik.com/design-system/docs/foundation/iconography/changelog/).

## Gantt, Grid, TreeList

`Items` (`IEnumerable<object>`) replaces the `Item` property in the following event argument types:

* `GanttTaskCommandEventArgs`
* `GridCommandEventArgs`
* `TreeListCommandEventArgs`
