# Breaking Changes in 15.0.0

## Icons

The v5 icon package removes and renames some icons and deprecates font icon aliases. Review the v5.0.0 notes in the [Icon Package Changelog](https://www.telerik.com/design-system/docs/foundation/iconography/changelog/) and update affected icon references.

The default SVG icon variant is now `outline`. This matches the appearance of most SVG icons in previous versions.

## Grid

To protect against spreadsheet formula injection (CWE-1236), the Grid now prefixes potentially executable string values in CSV exports with an apostrophe. This applies to values that begin with `=`, `+`, `-`, or `@`, including values preceded by spaces, and to values with leading tabs or line breaks. The protection also applies to exported headers, group headers, and aggregate text. Numeric values are not changed.

The change affects the raw CSV output. Applications that read CSV exports and depend on the original unescaped text must update their processing to account for the prefix. The behavior is always enabled and cannot be configured.

## Chart, Map

The [obsolete template syntax](slug:changes-in-14-0-0#chart-map) with literals and inline expressions is not supported. Instead, set the [Chart `Template` parameter](slug:components/chart/label-template-format#templates) and [Map `UrlTemplate` parameter](slug:components/map/overview) to the name of a JavaScript function that returns the required content. This change is also related to [CSP compliance](slug:troubleshooting-csp#policy-configuration).

## MultiSelect

The default value of the `MaxAllowedTags` parameter is changed from `null` to `10`.

## Scheduler

The [`SchedulerPopupEditFormSettings`](slug:scheduler-edit-popup-customization) parameters `Columns`, `ColumnSpacing`, and `Orientation` are removed.
