# Breaking Changes in 15.0.0

## Chart, Map

The [obsolete template syntax](slug:changes-in-14-0-0#chart-map) with literals and inline expressions is not supported. Instead, set the [Chart `Template` parameter](slug:components/chart/label-template-format#templates) and [Map `UrlTemplate` parameter](slug:components/map/overview) to the name of a JavaScript function that returns the required content. This change is also related to [CSP compliance](slug:troubleshooting-csp#policy-configuration).

## Scheduler

The [`SchedulerPopupEditFormSettings`](slug:scheduler-edit-popup-customization) parameters `Columns`, `ColumnSpacing`, and `Orientation` are removed.
